# HackClub-APPA
This is a Robot Appa, complete with 6 legs, a giant tail, fur (if you add it), and tied together with his personality. This is also my first Hack Club project, so I would love any feedback!

Appa is almost entirly 3d printed and runs off of Python. It uses a SEEED Main Board as its brain, which is connected to a motor controller. It uses an LED screen to display his face, and MG90s motors power his movement. He also uses 2 speakers to play classic Appa sounds.

I came up with the idea of robot Appa because of the new ATLA movie. I thought it would be a fun costume accessory if the movie ever comes to the theaters. His code runs on a randomized loop, making him perform actions like walking, running, and even dancing.

Later down the line, I would like to allow user input to Appa while keeping him autonomous, either using microphones with word detection or color sensors.
